# Chat web del copiloto (fase 9)

App Next.js 16 con shadcn/ui y Tailwind CSS v4. Usa el mismo agente que la terminal: importa el copiloto desde `../src`
y lee el `.env` de la raíz. Ver `specs/fase-09-streaming-web.md`.

Desde la raíz del repositorio (PowerShell):

```powershell
npm run web:install   # una vez: dependencias de web/
npm run web           # http://127.0.0.1:3000 (solo en esta máquina)
npm run web:build     # build de producción
```
